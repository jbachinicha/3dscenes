Drop your photos in this folder.

The scene looks for 01.jpg .. 08.jpg (one per frame along the road).
Any missing file falls back to a generated placeholder, so you can add
them one at a time.

To change the dates and captions, edit the MOMENTS array at the top of
  scenes/timeline/index.html

Landscape photos look best -- each frame is 3:2. Portrait works too,
it just gets letterboxed inside the mount.

Filenames can be anything you like as long as MOMENTS points at them,
e.g. photo: 'timeline/first-trip.jpg'
